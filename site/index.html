WODCraft est un petit langage pour prescrire des séances de fitness fonctionnel — et le compilateur qui les vérifie. Strict là où ça compte (unités, mouvements, cohérence du score, plausibilité), souple là où les coachs en ont besoin.

      01
      
Lisible par les athlètes

      
Tout fichier valide peut être affiché tel quel au mur de la box. Pas d'accolades, pas de YAML : la syntaxe du tableau blanc.

    

    

      02
      
Vérifié par un compilateur

      
Un box jump attend une hauteur, pas une charge. 1 m Run demande si vous vouliez 1 mi. Un EMOM intenable est signalé.

    

    

      03
      
Un seul format d'échange

      
Le JSON compilé suit un schéma versionné : c'est lui que s'échangent les timers, les applications et les agents IA.

    

    

      04
      
Converti pour vous

      
Les charges portent kilos et livres, avec les équivalences réellement utilisées en box : 95 lb ↔ 43 kg, 24 in ↔ 60 cm.

    07
    
Partout où vit un WOD

    
Une spécification, un schéma, une suite de conformité — et deux implémentations qui se vérifient l'une l'autre.

  

  

    
Terminal
Vérifier, afficher, formater comme gofmt, exporter vers l'agenda.

      
$ wodc check mardi.wod
$ wodc show girls/fran --me
$ wodc fmt --write mardi.wod
$ wodc export ics semaine.wod

    
Éditeur
Serveur de langage et extension VS Code : diagnostics en direct, complétion des mouvements, survol, corrections rapides.

      
python -m wodcraft.lsp

    
Agents IA
Un serveur MCP expose le compilateur lui-même. L'agent rédige un WOD, le compilateur répond, l'agent corrige.

      
check_wod · compile_wod · show_wod
format_wod · timeline_wod
search_movements · library_get

    
iOS · macOS
WODCraftKit : le langage porté en Swift, hors ligne, validé par la même suite de conformité.

      
import WODCraftKit

    
Service HTTP
Pour les clients qui ne peuvent pas embarquer le compilateur. Image Docker prête pour Cloud Run.

      
POST /compile  /check  /format  /show
GET  /catalog  /library

    
Le standard
Spécification (CC BY-SA), JSON Schema versionné et cas de conformité : WODCraft est fait pour être réimplémenté.

spec/workout.schema.json
